# Cosmo Dance-Off

Dance Cosmo the Cougar's 2017 routine with the Cougarettes (BYU vs Boise
State, to Ayo & Teo's "Rolex"). A laptop's or phone's camera watches up
to four dancers and grades every two beats PERFECT / GOOD / OK / MISS
against Cosmo's own moves. Made for one Holy War game-day party; personal
use.

Open the site, press **Let's dance**, allow the camera, line up where it
can see you head to toe, **Start the song**. Tap a player's card to give
them a name.

Everything runs in the browser: the pose model (MediaPipe) is in `web/`,
nothing is sent anywhere. See `HANDOFF.md` for how it works.
